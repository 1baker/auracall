# ChatGPT Single-Session File Materialization | 0164-2026-07-23

State: OPEN
Lane: P01
Plan version: 1

## Goal

Materialize every selected file from one ChatGPT conversation through one
retained browser tab/client session, iterating the files within that session
without per-file tab attachment, navigation, readiness recovery, or provider
retry envelopes.

  from one conversation and attempted 12 transfers.
- Telemetry recorded 14 `chatgpt.connectTab.start` actions, 12
  `downloadConversationFile` actions, 13 `Runtime.evaluate` calls, and zero
  successful transfers.
- Every transfer reported
  `direct_download_json_missing_url:status_403`; two also reported

## Scope

- Add an optional provider batch-download contract with per-file destinations
  and per-file outcomes; retain the singular fallback for providers without it.
- Make ChatGPT acquire and validate one conversation surface once, then iterate
  the selected files on the retained client.
- Prefer the download request generated by the visible file tile. Keep any
  identifier-derived direct endpoint as a bounded fallback, not the first
  request for a matched tile.
- Intercept and suppress matching anchor/window navigation on the retained
  page, click the preview viewer's exact `Download` control when required, and
  fetch the captured signed URL in that same page rather than opening a native
  download or another tab.
- Preserve one-file-at-a-time payload transfer/write behavior inside the
  retained session so a batch does not accumulate all file bodies in CDP
  memory.
- Emit sanitized, attributable failure diagnostics without persisting signed
  URLs, cookies, tokens, or full response bodies.
- Make an all-failed materialization result terminally failed rather than
  skipped.
- Confirm that force/idempotency overrides do not bypass a provider rate-limit
  guard.

## Non-Goals

- No increase to live-follow interaction-rate limits.
- No guard clearance, scheduler resume, or repeated provider probes.
- No redesign of Gemini/Grok file retrieval.
- No parallel downloads from one conversation.
